# VITALS 单人公开版设计

用户已确认：保留 WorkBuddy 为手机与电脑入口，同时支持 Windows/macOS，每次安装管理一个人。

## 使用流程
用户把仓库地址和安装指令发给桌面 WorkBuddy。助手读取 INSTALL.md，检查 Python 3.10+，运行幂等初始化与 doctor，建立独立档案。手机端使用自己的账号连接自己的在线电脑。记录无需始终运行面板服务；看图表时启动本地服务。

健康记录技能把图片/文字转换为结构化记录，通过 CLI 提交。保存后读取回执；可查询、修改、删除。截图使用附件内容摘要或 SHA-256 去重，重复提交返回原记录。纠错通过 ID 更新，不重复新增。原始图片可由 CLI 复制进本地附件目录；无法访问附件文件时如实说明不保留原图。

## 组件
- Python 标准库共享存储：跨进程锁、原子替换、80 份备份、修订冲突检测、结构校验。
- CLI：保留已有子命令，新增 JSON record/list/update/delete 命令与 sourceKey 幂等键。
- 本地面板：保留六个视图；修复 CSV、保存竞争和只读误操作。
- WorkBuddy 项目规则和项目级 Skill：新对话仍能获得录入与纠错规则。
- 安装/检查脚本、macOS/Windows 启动入口、中文文档、MIT 许可证及 CI。

## 数据边界
程序与运行时 data 目录分离，模板位于 templates。发布采用文件白名单，不复制原项目数据、历史备份、.workbuddy 记忆或个人规则。更新不删除/覆盖 data。初始化默认仅记录，不预设减脂、性别、生日或热量目标；缺少计算信息时不生成相关指标。

照片识别由 WorkBuddy 提供，不能声称完全离线。照片营养为估算，不提供诊断、用药调整或针对所有老人的默认饮食处方。

## 验收
临时目录完成初始化、反复安装保留数据、CLI 录入/去重/纠错/删除、附件保存、备份/冲突/并发验证、API 来源校验与静态文件范围验证、CSV 同日两时段保留及列映射验证。Mac 浏览器检查空白/演示/真实测试数据各视图。CI 配置 Windows/macOS；未执行的 Windows 实机与 WorkBuddy 端到端流程明确列为待验收。
