# 对话录入与纠错接口

下文使用 python3，Windows 换成已验证可用的 `py -3` 或 `python`。命令在项目根目录执行；用 UTF-8 JSON 文件传复杂内容，避免拼接 shell。临时 JSON 放入 data/inbox/，不要放公开源码区，用完可移除。

## 查询

```bash
python3 tools/log.py profile
python3 tools/log.py list --kind meal --date 2026-10-26
python3 tools/log.py list --kind body
python3 tools/log.py show --date 2026-10-26
```

kind 为 body / activity / meal / workout / supp。list 返回 records、revision；日期可省略。profile 无修改参数时只读。日期示例不代表用户实际日期，录入使用用户给出的实际日期。

## JSON 录入

例如 data/inbox/meal.json：

```json
{
  "date": "2026-10-26", "slot": "lunch", "title": "米饭与鸡蛋（估算）",
  "items": [
    {"name": "熟米饭", "amount": "约150 g", "kcal": 174, "proteinG": 3.9, "fatG": 0.5, "carbG": 38.9, "fiberG": 0.5},
    {"name": "鸡蛋", "amount": "约50 g", "kcal": 72, "proteinG": 6.3, "fatG": 4.8, "carbG": 0.6, "fiberG": 0}
  ],
  "confidence": "estimated", "note": "照片份量估算，油量未知"
}
```

```bash
python3 tools/log.py record --kind meal --file data/inbox/meal.json --source-key "meal:原消息稳定标识" --photo "实际原图路径.jpg"
```

--photo 可省略；只有实际文件存在才传。图片复制至 data/attachments，文件名取 SHA-256。相同图片在同类记录中去重。--source-key 可选，来自原消息，重试不改变；无来源键/图片时按 JSON 内容摘要去重。同一天确实发生的两次相同餐食，使用不同原消息键。不要为重试随机生成新键。图片内相同文件是否为另一次真实记录有争议时先问，不绕过去重。

--file - 支持标准输入。返回 ok、duplicate、record（含 ID）、revision。CLI 已执行备份和校验，不能再手改 JSON“补救”。已删除记录的来源重试返回 duplicate=true、deleted=true、record=null，不重新创建；需要重新记录时由用户明确说明。所有写入需要完整档案通过校验，出错时原 JSON 不变。

其他类型的 JSON 最小例子：

```json
{"date":"2026-10-26","measureMode":"fasting","weightKg":70.2,"bodyFatPct":24.1,"source":"xiaomi_scale"}
```

```json
{"date":"2026-10-26","type":"walking","typeLabel":"散步","durationMin":30,"note":"热量未估算"}
```

```json
{"date":"2026-10-26","steps":6000,"sleepMin":450,"activeKcal":300}
```

```json
{"date":"2026-10-26","name":"乳清蛋白","dose":"30 g","nutrients":{"kcal":118,"proteinG":24}}
```

分别配 body/workout/activity/supp。ts 可选，只在知道具体测量/发生时刻时提供合法 ISO 时间，不用当前上传时刻伪造。未知数值省略，不写 null 充当测量。体重必须明确时段；source 使用设备名或 manual/conversation，如 xiaomi_scale。活动消耗 activeKcal 与全天总消耗 totalKcal 分开，不能互相替代。缺少体重等估算依据时运动 kcal 可省略。

## 按 ID 纠错与删除

先 list 定位，将修改字段写入 data/inbox/correction.json：

```json
{"items":[{"name":"熟米饭","amount":"半碗","kcal":87,"proteinG":2,"fatG":0.2,"carbG":19.4,"fiberG":0.2}]}
```

items 会整组替换，必须包含这餐保留的所有食物；工具重算 totals。只改米饭时不能遗漏原来的其他食物。

```bash
python3 tools/log.py update --kind meal --id "list返回的实际ID" --file data/inbox/correction.json
python3 tools/log.py delete --kind meal --id "list返回的实际ID"
```

id/sourceKey/createdAt/photo 是系统字段，不能通过纠错随意改写。删除记录不会删除原图和历史备份，隐私清理见维护说明。

## 原有简写命令

保留 profile/body/meal/workout/supp/activity/show 子命令。体重显式传 --date、--time、--mode。meal 的 --item 要求七段：`名称|克数|热量|蛋白|脂肪|碳水|纤维`。新增照片、纠错和幂等操作使用上述 JSON 接口。
