# 公开版验证记录

版本：0.1.0；日期：2026-10-26。

验证状态由当前交付时的实际执行结果更新。自动化测试均使用临时目录，不读取原个人项目的数据。

## 验收边界

- macOS：本地执行 Python/JavaScript 自动化验证，以及浏览器检查，详见下方结果。
- Windows：提供启动.bat、标准库文件锁实现、中文/空格路径测试和 GitHub Actions Windows 矩阵；尚未在 Windows 实机执行；CI 实际状态见仓库 Actions，不将配置文件当成测试结果。
- WorkBuddy：技能目录和安装流程按官方项目/技能文档组织；尚未在全新 WorkBuddy 账号与手机/电脑组合上完成真实端到端测试。
- 图片识别：属于 WorkBuddy 所用模型能力，本项目自动测试不验证真实食物识别准确率。

## 发布前人工验收

Windows 与 macOS 各找一位全新用户：发送仓库地址和安装指令，记录实际 Python 命令、安装路径、doctor 输出、技能是否加载。发送一餐照片、同图重发、运动描述、体脂截图、模糊截图、纠错、查询；检查是否保存成功、是否去重和是否需要适当追问。锁屏与电脑离线时核对提示。

Windows 另验证双击启动、中文空格路径、两进程同时录入、备份/原子替换和浏览器保存。只测试脚本语法或上传 CI 配置不等于该验收通过。

## 本地执行结果

- 本地 macOS / Python 3.15：18 项 Python 自动测试通过（unittest）。
- Node：11 项前端测试通过；两个 JavaScript 文件语法检查通过。
- 所有 Python 源文件通过 Python 3.10 语法解析检查；这不是 Python 3.10 实际运行验证；远程 CI 的实际运行结果见下方。
- Chrome / Playwright：空白档案六个视图、虚构演示六个视图、深浅主题、保存后 API 回读、其他写入者更新后的冲突拦截均通过，无页面脚本错误。
- 390px 宽度：六个视图无页面横向溢出；图表与表格可显示。
- 技能元信息通过 skill-creator quick_validate 校验；本项目运行不依赖该外部校验器或 PyYAML。
- 发行包按白名单生成并在中文/空格目录解压，完成空白初始化；个人 data、.workbuddy、缓存和 Git 元数据未进入 ZIP。
- 独立代码审查发现的活动 ID、旧运动命令默认数据和称重替换 ID 问题已修复并通过回归测试。
- 原项目数据、历史备份、项目说明和原程序文件哈希比对一致。

待完成：Windows 实机、全新 WorkBuddy 手机/电脑账号组合的真实端到端验收。GitHub 发布后的远程 CI 结果见 [Actions](https://github.com/bjfuzzj/self-health/actions/workflows/test.yml)。
