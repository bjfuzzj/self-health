# 隐私说明

默认个人档案、历史快照和原始附件存放在运行电脑的 data 目录。项目面板不包含分析统计脚本、远程字体、第三方图表或自动上传服务；Python HTTP 服务仅监听 127.0.0.1。

使用手机或电脑 WorkBuddy 发送图片、语音和文字时，内容会按 WorkBuddy 及其所用模型服务的机制处理。本地保存不代表图片识别完全离线。是否发送照片由用户决定；可只发文字或在本地面板填表。

data 中的文件未加密，拥有本机相应文件权限的人可能读取。请使用自己的系统账户，保护电脑与备份。GitHub 发布只包含源码和虚构模板；.gitignore 排除数据不等于已有提交能自动清除，上传前检查实际文件和历史。

记录删除后，原始图片和自动备份仍可能保留。需要彻底清理时关闭服务，按 docs/维护与备份.md 检查附件、备份及 WorkBuddy 会话/附件留存；本工具不会替你删除外部服务中的消息。

项目无用户注册、遥测、广告或家庭共享账号。每次安装只有一个个人档案。面向家庭成员分别使用时，应各自安装并登录各自的 WorkBuddy 账号。
